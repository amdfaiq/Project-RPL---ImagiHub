Platform berbasis web yang dikembangkan untuk memungkinkan pengguna menemukan, menyimpan, dan membagikan inspirasi visual dalam bentuk gambar.

**Tech Stack**
Frontend: HTML, CSS
Backend: Python, Django

Features
1. **Pendaftaran (Sign Up)**
   Pengguna mendaftar ke web Imagihub dengan mengirimkan permintaan pendaftaran. Web Imagihub memproses permintaan pendaftaran tersebut dengan memeriks kredensial dan informasi yang diberikan oleh pengguna.

2. **Masuk (Sign In)**
   Pengguna masuk ke akunnya dengan mengirimkan permintaan masuk. Web Imagihub memeriksa kredensial yang diberikan oleh pengguna dengan data yang tersimpan dalam basis data. Jika kredensial valid, pengguna berhasil masuk ke akunnya.

3. **Menelusuri Gambar (Browse Images)**
   Pengguna menjelajahi gambar-gambar yang tersedia di web Imagihub.

4. **Menyimpan Gambar (Save Image)**
   Pengguna menyimpan gambar yang disukai ke dalam koleksi pribadinya.
   
5. **Membuat Board (Create Board)**
   Pengguna membuat papan (board) baru untuk mengumpulkan dan mengatur gambar sesuai dengan tema atau minat tertentu.
   
6. **Mengelola Board (Manage Board)**
   Pengguna mengelola board yang sudah dibuat, seperti mengedit, menghapus, atau mengatur ulang gambar-gambar di dalamnya.
   
8. **Membagikan Gambar (Share Image)**
    Pengguna membagikan gambar ke platform lain atau kepada pengguna lain di Imagihub.
